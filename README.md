# Banana Studio

Photoshopの操作に慣れた人のための、Nano Banana 2.1 画像生成・編集ウェブアプリです。暗い作業画面、左のツールバー、画像レイヤー、選択範囲、履歴、ショートカットを備えています。React / TypeScriptで実装し、各利用者自身のGemini APIキーでGoogleへ直接接続します。

![編集画面](docs/screenshots/editor-desktop.png)

## 起動

Macでは、このフォルダの **`Banana Studioを起動.command` をダブルクリック**します。インストール済みのNode.js 22.12以降が必要です。ターミナルから起動する場合は以下を実行します。

```sh
cd /Volumes/ROCKET_XTRM/coding/nano-banana-2-1-app
npm ci --ignore-scripts
npm run build
npm start
```

ブラウザで `http://127.0.0.1:4173` を開きます。キーがなくても、画像を開く、レイヤーを編集する、選択を描く、保存・書き出しを行うことができます。右上の「APIキーを設定」から、利用者自身のキーを入力してください。キーを設定するだけでは有料生成を実行しません。

**APIキーを扱うときは `npm start` の本番用サーバーを使ってください。** `npm run dev` は画面開発用で、キーの接続を無効にしています。本番用サーバーは文書とWorkerに異なるCSPを設定します。別の静的ホストへファイルだけをコピーすると、この保護が失われます。

## 操作と実装機能

- **画像編集:** PNG/JPEG/WebPの読み込み、画像レイヤー追加、移動、表示切替、不透明度、順序変更、削除、文字のラスターレイヤー、キャンバス拡張。
- **選択とスケッチ:** 選択ブラシ、選択消去、矩形選択、手描き線。部分編集では元画像と注釈画像をGoogleに送り、採用時にアプリ自身が選択範囲だけを合成します。
- **AI:** 新規生成、全体編集、部分編集、スケッチ指示、候補の確認と採用、会話履歴・thought signatureの引き継ぎ。
- **モデル設定:** 正式ID `gemini-nano-banana-2.1`、1K/2K/4K、14種類の比率、minimal/medium/highの思考設定、Web検索・画像検索と出典表示。
- **参照入力:** 画像、PDF、MP4/WebM/MOVをインラインで送信。画像は履歴・編集元を含め最大14枚。単体14MiB以下、送信JSON全体19MB以下に制限します。
- **Batch:** 1行1指示、最大20件の非同期生成。作成・状態取得・中止要求・画像採用。検索と参照素材は使いません。最後のジョブIDと状態だけを保存し、再読込後に復旧できます。
- **保存:** ブラウザ内に1プロジェクトを保存、独自JSONプロジェクトの読み書き、PNG書き出し、最大24ステップのUndo/Redo。

| 操作 | ショートカット |
|---|---|
| 移動 / 選択ブラシ / 選択消去 / 矩形 / 文字 | V / B / E / M / T |
| パン | Spaceを押しながらドラッグ |
| 元に戻す / やり直す | ⌘Z / ⇧⌘Z（WindowsはCtrl） |
| ブラウザ内保存 | ⌘S / Ctrl+S |
| ズーム / ブラシサイズ | +・− / [・] |

文字は画像レイヤーに変換されます。PSD互換、調整レイヤー、描画モード、印刷用CMYK、任意サイズのファイルアップロード、Google Files API、モデルの全APIオプションは未実装です。文書は各辺16,384px・3,200万画素以下、最大40レイヤー。新規作成と拡張は各辺8,192pxまでです。生成結果の受信全体は80MBまでなので、大量の4K Batch結果は取得できない場合があります。

## キーとデータの扱い

キーは入力時だけ画面を通過し、その後は専用Workerの一時メモリで保持します。Reactの状態、localStorage、sessionStorage、IndexedDB、プロジェクト、URL、アプリサーバーには保存しません。Google宛ての `x-goog-api-key` ヘッダーにだけ付け、リダイレクトを拒否します。解除、ページ離脱、15分の無操作でWorkerを終了します。

外部スクリプト・CDN・解析サービスを使わず、画面からのネットワーク接続をCSPで禁止し、Workerの接続先をGoogleに限定しています。APIの生エラーは表示せず、成功応答に入力キーが含まれる場合にも伏字にします。検索のHTMLはスクリプトと外部リソースを無効にしたsandbox内で表示します。

**絶対に漏洩しないという保証はできません。** 悪意あるブラウザ拡張、端末侵害、配布コードの改ざんまでWorkerで防げるものではありません。JavaScriptメモリの確実なゼロ化も保証しません。詳しい境界、Google側のAPI制限、公開時の条件は [security.md](docs/security.md) に記載しました。

指示・素材・必要な会話履歴は、生成ボタンを押した際にGoogleへ送信されます。Google側の処理・保持条件はサービス規約と契約に依存します。キーを破棄しても、Googleへ既に送信したデータや作成したBatchジョブは削除されません。プロジェクトには画像が含まれるため、共有先に注意してください。

npm run check
