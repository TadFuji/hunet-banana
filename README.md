# Banana Studio

Photoshopの操作に慣れた人のための、Nano Banana 2.1 画像生成・編集ウェブアプリです。暗い作業画面、左のツールバー、画像レイヤー、選択範囲、履歴、ショートカットを備えています。React / TypeScriptで実装し、各利用者自身のGemini APIキーでGoogleへ直接接続します。

![編集画面](docs/screenshots/editor-desktop.png)

## 公開アプリを使う

公開URLは **https://hunet-banana-studio.vercel.app/** です。デスクトップ版Chromeで開いてください。VercelへのログインやNode.jsのインストールは不要です。アプリの「ヘルプ」から図解の取扱説明書を開けます。各利用者が自分のGemini APIキーを入力し、生成料金も自身のGoogleプロジェクトに発生します。キーを設定するだけでは画像生成を実行しません。

生成時に「指定モデル」を利用できないと表示された場合は、右上の「キー接続中」から **「モデル接続を確認（生成なし）」** を押してください。Googleのモデル情報を取得して、API版ごとの応答を表示します。画像生成は実行せず、実際の生成権限・課金・利用枠まで確認するものではありません。表示された短い結果だけを共有し、キーの値は共有しないでください。通常の生成がv1で404となった場合だけ、同じモデルのv1beta側の情報を確認し、対応を確認できた場合に同じ指示を1回だけ再送します。別モデルへは切り替えません。

作品のブラウザ内保存はURLのオリジンごとに独立します。ローカル版や別のURLへ移る際はJSONを書き出して読み込んでください。

アクセス時と再読み込み時には、灰色のキャラクターが動く「Loading…」の起動画面を5秒間表示してから編集画面を開きます。これは歓迎用の演出で、GoogleへのAPI通信や画像生成は行いません。OSやブラウザで動きを減らす設定を使用している場合は静止画で表示します。

## ローカルで起動

Macでは、このフォルダの **`Banana Studioを起動.command` をダブルクリック**します。インストール済みのNode.js 22.12以降が必要です。ターミナルから起動する場合は以下を実行します。

```sh
cd /Volumes/ROCKET_XTRM/coding/nano-banana-2-1-app
npm ci --ignore-scripts
npm run build
npm start
```

ブラウザで `http://127.0.0.1:4173` を開きます。キーがなくても、画像を開く、レイヤーを編集する、選択を描く、保存・書き出しを行うことができます。右上の「APIキーを設定」から、利用者自身のキーを入力してください。キーを設定するだけでは有料生成を実行しません。

**APIキーを扱うときは `npm start` の本番用サーバーを使ってください。** `npm run dev` は画面開発用で、キーの接続を無効にしています。本番用サーバーは文書とWorkerに異なるCSPを設定します。別の静的ホストへファイルだけをコピーすると、この保護が失われます。

## 操作と実装機能

- **画像編集:** PNG/JPEG/WebPの読み込み、画像レイヤー追加、移動、表示切替、不透明度、順序変更、削除、文字のラスターレイヤー、キャンバス拡張。
- **選択とスケッチ:** 選択ブラシ、選択消去、矩形選択、手描き線。部分編集では元画像と注釈画像をGoogleに送り、採用時にアプリ自身が選択範囲だけを合成します。
- **AI:** 新規生成、全体編集、部分編集、スケッチ指示、候補の確認と採用、会話履歴・thought signatureの引き継ぎ。
- **モデル設定:** 正式ID `gemini-nano-banana-2.1`、1K/2K/4K、14種類の比率、minimal/medium/highの思考設定、Web検索・画像検索と出典表示。
- **参照入力:** 画像、PDF、MP4/WebM/MOVをインラインで送信。画像は履歴・編集元を含め最大14枚。単体14MiB以下、送信JSON全体19MB以下に制限します。
- **Batch:** 1行1指示、最大20件の非同期生成。作成・状態取得・中止要求・画像採用。検索と参照素材は使いません。最後のジョブIDと状態だけを保存し、再読込後に復旧できます。
- **保存:** ブラウザ内に1プロジェクトを保存、独自JSONプロジェクトの読み書き、PNG書き出し、最大24ステップのUndo/Redo。

| 操作 | ショートカット |
|---|---|
| 移動 / 選択ブラシ / 選択消去 / 矩形 / 文字 | V / B / E / M / T |
| パン | Spaceを押しながらドラッグ |
| 元に戻す / やり直す | ⌘Z / ⇧⌘Z（WindowsはCtrl） |
| ブラウザ内保存 | ⌘S / Ctrl+S |
| ズーム / ブラシサイズ | ⌘+・⌘−（WindowsはCtrl） / [・] |

文字は画像レイヤーに変換されます。PSD互換、調整レイヤー、描画モード、印刷用CMYK、任意サイズのファイルアップロード、Google Files API、モデルの全APIオプションは未実装です。文書は各辺16,384px・3,200万画素以下、最大40レイヤー。全レイヤーの文書画素合計と埋込画像の実寸合計は、それぞれ1億2800万画素までです。新規作成と拡張は各辺8,192pxまでです。生成結果の受信全体は80MBまでなので、大量の4K Batch結果は取得できない場合があります。

## キーとデータの扱い

キーは入力時だけ画面を通過し、その後は専用Workerの一時メモリで保持します。Reactの状態、localStorage、sessionStorage、IndexedDB、プロジェクト、URL、アプリサーバーには保存しません。Google宛ての `x-goog-api-key` ヘッダーにだけ付け、リダイレクトを拒否します。解除、ページ離脱、15分の無操作でWorkerを終了します。

外部スクリプト・CDN・解析サービスを使わず、画面からのネットワーク接続をCSPで禁止し、Workerの接続先をGoogleに限定しています。APIの生エラーは表示せず、成功応答に入力キーが含まれる場合にも伏字にします。検索のHTMLはスクリプトと外部リソースを無効にしたsandbox内で表示します。

**絶対に漏洩しないという保証はできません。** 悪意あるブラウザ拡張、端末侵害、配布コードの改ざんまでWorkerで防げるものではありません。JavaScriptメモリの確実なゼロ化も保証しません。詳しい境界、Google側のAPI制限、公開時の条件は [security.md](docs/security.md) に記載しました。

指示・素材・必要な会話履歴は、生成ボタンを押した際にGoogleへ送信されます。Google側の処理・保持条件はサービス規約と契約に依存します。キーを破棄しても、Googleへ既に送信したデータや作成したBatchジョブは削除されません。プロジェクトには画像が含まれるため、共有先に注意してください。

## 検証と資料

公開後の再レビューで、画像準備中のキー切替、画像検索の出典、Batchの画像なし応答の集計を修正しました。詳細は[再レビュー報告](docs/re-review-2026-10-13.md)を参照してください。

図解の取扱説明書は [Banana Studio 図解取扱説明書（PDF）](output/pdf/Banana_Studio_図解取扱説明書.pdf) です。APIキーの取得から初回生成、編集、保存、料金の確認までを22ページで説明しています。再生成の手順は [説明書の制作メモ](docs/manual/README.md) を参照してください。

2026-10-13のAstraを中心とする独立レビューで、編集・保存・Batch・不正画像読込の指摘を修正し、単体13件・ブラウザ22件のテストが通過しました。[レビュー報告](docs/review-2026-10-13.md) に修正内容と未確認範囲を記載しています。

```sh
npm run check
npm run test:e2e
npm audit
```

ブラウザテストはインストール済みGoogle Chromeを使い、生成通信にはダミーキーとモック応答を使用します。2026-10-13にVercelへ本番公開し、モデル接続診断と404時の限定再試行を追加した版で、単体15件・ローカルと公開URLのE2E各38件が成功しました。匿名アクセス、文書とWorkerのセキュリティヘッダー、PDF配信、配信ファイルとローカルビルドのバイト一致を確認しています。

同日、利用者本人のGemini APIキーで「白い背景に赤いリンゴを1個」の実生成が成功したとの報告を受け、添付画像でも生成候補と「キャンバスに採用」ボタンを確認しました。本人に生成→キャンバスに採用→PNG書き出し→キー切断を案内し、「うまくいきました」との回答を受けています。採用・書き出し・切断の各操作は個別には観察していません。他の利用者のGoogleプロジェクトでの動作、実APIの部分編集・スケッチ・検索・Batchは未確認です。[公開・引き継ぎ記録](docs/deployment.md) を参照してください。
