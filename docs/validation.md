単体テストは、正式な生成パラメーター、思考署名の引き継ぎ、履歴を含む14画像制限、不正入力、Batch ID・出力の解析、安全なURL、選択外RGBAのコピー、キーなどの追加フィールドをプロジェクトに書き出さないことを検証する。

初期のブラウザテストは以下の8件。

1. Photoshop風のレイアウト、矩形選択、Undo/Redo、IndexedDB保存、JSON書き出し。
2. Google宛てのヘッダーだけにダミーキーを付ける。URL・本文・DOM・各Storage・コンソールに残さず、応答に含まれたキーを伏字にする。解除と再読込で切断する。
3. 文書とWorkerそれぞれのCSP、クエリ文字列でCSPを変えられないこと、POSTを受け付けないこと、Googleの生エラーを表示しないこと。
4. 15分の無操作でWorkerとキーを破棄する。
5. Google APIから別オリジンへのリダイレクトを追わないこと。
6. 部分編集で候補の全画素を赤に変えても、未選択の元の青い画素が一致し、完全選択部分だけ赤になること。
7. 検索のHTML内のスクリプトが実行されず、外部の追跡画像へ通信しないこと。
8. 公式Batchパスで作成・再読込からのID復旧・更新・中止要求・結果取得を行い、キーを保存しないこと。

部分編集の検証中、選択描画をコミットした直後の非同期再描画で、一時的に選択Canvasが空になる問題を見つけた。画像のデコードが終わってから描画を置き換えるよう修正し、8件すべてが通過した。修正後は部分編集の検証をさらに3回繰り返し、すべて成功した。

## 独立レビュー後の追加確認

単体テストに5件を追加。不正なBatch状態・出力配列、生成結果の不正形式、非表示画像のデコード失敗、画像の実寸上限、全画像の合計画素上限を検証した。

ブラウザテストに14件を追加。不正画像を含むJSON読込・IndexedDB復元の拒否、40レイヤー上限時の候補保持、異なる画像寸法でのレイヤー移動・拡張、拡張中の編集保護、保存ボタンとショートカットの保存表示、古いBatch応答の拒否、作成中のジョブID保持、不正Batch状態の処理、実画像合計上限での候補保持、選択・名称変更後の思考署名引継ぎ、下部と右の履歴復元後の選択保持を検証した。大きな画像の合計上限のテストはデコーダの寸法を模擬し、巨大画像は割り当てていない。

最終版で `npm run check`（ビルド＋単体13件）、`npm run test:e2e`（22件）、`npm audit --json`（開発依存を含め検出0件）、`git diff --check` が成功。Astraの再レビューはソース読解、隔離ブラウザでの再現は各担当と本体の実測として区別している。詳細は [レビュー報告](review-2026-10-13.md) を参照。

説明書も新規生成の参照素材案内・ズームキー・全レイヤー画素上限を更新。全22ページをPNGに再描画して確認し、21ページの表と注記の間隔を調整した。日本語テキスト、23件のHTTPSリンク、22件のしおりを確認した。

## 未確認と適用範囲

生成API通信はすべてダミーキーとモック応答。実キーの読取・使用、有料画像生成、実モデルの画質・速度、実アカウントの課金・利用枠・リファラー制限は確認していない。公式仕様との照合とモックでの要求確認は、Googleから実際に生成画像が返ることの実証とは区別する。

Safari・Firefox・モバイルの自動テスト、スクリーンリーダーによる全面的なアクセシビリティ検査、公開HTTPSホストでのヘッダー・CORS検証は未実施。現在はローカルで利用できるウェブアプリであり、他人がアクセスする公開URLは作っていない。

未選択画素の確認はCanvasに描画された元画像を基準とする。元ファイルの圧縮バイト、EXIF、カラープロファイル、不可視RGBの一致を保証する検査ではない。モデルの選択範囲理解やスケッチ解釈の品質は、実素材と実キーで今後確認する。

既知の制限は [README](../README.md) と [セキュリティ設計](security.md) に記載。PSDやFiles API、80MBを超えるBatch応答には対応していない。
