# 図解取扱説明書の制作メモ

成果物は `output/pdf/Banana_Studio_図解取扱説明書.pdf`（A4縦・22ページ）です。実際のアプリ画面、手順番号、説明図、料金表を使い、PhotoshopユーザーがAPIキーの取得から初回生成・保存まで進められる構成にしています。

## 再生成

1. アプリを本番ビルドのローカルサーバー `http://127.0.0.1:4173/` で起動します。
2. 必要な場合だけ `node docs/manual/capture.mjs` で画面を撮り直します。プロジェクトのPlaywrightとインストール済みGoogle Chromeを使います。
3. ReportLab・Pillowを利用できるPythonで `python3 docs/manual/build_manual.py` を実行します。macOSの `Arial Unicode.ttf` をPDFに埋め込みます。
4. Poppler等で全ページをPNGに変換し、重なり・欠け・画面の文字を確認します。pypdf等でページ数・日本語テキスト・リンクも確認します。

`capture.mjs` は利用者のブラウザとは別の隔離コンテキストで動作します。Google APIへの通信をローカル応答に置き換え、説明専用のダミーキーを使います。実キー・有料生成・利用者の保存済み作品は使用しません。候補画面は実APIの生成結果ではないことをPDFに明記しています。Googleのキー管理や課金設定は図解で、実際の管理画面の写真ではありません。

## 更新時の確認

- 料金・キーの取得・課金・Auth key制限は2026年10月13日のGoogle公式資料で照合。料金と重要な設定案内には独立したAstraのレビューを実施しています。
- 円換算は比較用に1 USドル = 150円を固定。実勢為替・税・入力・思考・検索の料金は画像出力表に含みません。
- 通常4Kは公式の丸め表示$0.113と、3,780トークンからの計算値$0.1134の関係を注記しています。
- 操作説明はアプリ実装と照合。実キーでのGoogle接続・有料生成・実請求は未検証です。
- PDFにはクリック可能な公式資料リンクとページのしおりがあります。中間の `layout-check.json` とレンダリング画像はGitに含めません。

アプリの仕様や画面を変えた場合は、本文とスクリーンショットを一緒に更新してください。PDFの確認日と料金確認日も更新します。

## 第1版の確認結果

全22ページをPNGにレンダリングして確認し、表紙の説明が重なっていた箇所を修正しました。実画面の掲載は13箇所、クリック可能なリンクは23件、しおりは22件です。pypdfでページ番号・日本語テキスト・料金表の値・HTTPSリンクを確認し、日本語フォントの埋め込みも確認しました。画面画像とPDFは説明専用の素材から生成しており、実APIキーは含みません。

同日の独立レビュー後、新規生成で参照素材を使える旨の画面案内、⌘/Ctrl付きのズームキー、全レイヤーの画素上限を更新しました。隔離ブラウザで画面を撮り直し、PDFを再生成。全22ページの再描画を確認し、21ページの注記が下にはみ出さないよう間隔を調整しました。日本語テキスト、リンク23件、しおり22件を再確認しています。
